# longvinter-mapping
Longvinter UE 5.7.2 mapping file (.usmap)

롱빈터 UE 5.7.2 매핑 파일 (.usmap)

## How to Use

1. Download the `.usmap` file from this repository
2. Open your data mining tool (e.g., FModel)
3. Load this mapping file in the settings to correctly view the game's internal structure and asset names

## 사용 방법

1. 이 리포에서 `.usmap ` 파일을 다운로드합니다.
2. FModel같은 툴을 실행합니다.
3. 설정에서 이 매핑 파일을 불러오세요.
